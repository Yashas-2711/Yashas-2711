## 🚀 Featured Projects

### 💊 MediScan-AI — Medicine Identification App

An AI-powered mobile application designed to identify medicines from captured or uploaded images and provide useful medicine information.

**Key Features**

* 📷 Capture or upload medicine images
* 🤖 Identify medicine names using the Google Gemini API
* 💊 Display generic name, dosage, uses, side effects, warnings, manufacturer, and category
* 📊 Provide AI confidence information
* 🔊 Support text-to-speech for medicine information
* 🗂️ Store user scan history
* 📱 Designed for Android using React Native and Expo

**Technology Stack**

`React Native` `Expo` `TypeScript` `Gemini API` `AsyncStorage` `Text-to-Speech`

**Status:** 🚧 Active Development
